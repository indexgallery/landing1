# Управление каталогом и сайтом

Откройте /admin.html и введите пароль администратора. Локально он находится в ADMIN_PASSWORD файла .env. Для выхода используйте «Выйти».

## Объекты и категории

1. Выберите карточку либо нажмите «Добавить объект».
2. Заполните название, резидента, категорию, цену, характеристики и описание. Цена допускает текст: «150 000 ₽», диапазон или «По запросу». Размеры задаются свободным текстом.
3. Можно создать свою категорию. Удалять можно пустые пользовательские категории.
4. Загрузите JPG, PNG или WebP до 8 МБ, максимум 12 фото. Первое — главное. Стрелками меняется порядок; остальные фото появляются в карусели.
5. Для нескольких исполнений добавьте варианты и заполните оба поля. Для одного исполнения варианты не нужны.
6. «Сохранить объект» сразу публикует изменения. Стрелки в списке объектов тоже сохраняют порядок на сайте.

Фото отправляется в хранилище при выборе файла. Карточка публикуется после сохранения. При ошибке соединения не закрывайте страницу до успешного сохранения.

## Информация сайта

Выберите «Информация на сайте», разверните раздел и внесите правки. Предпросмотр меняется при вводе. «Сохранить информацию» публикует изменения. Открытая страница посетителя получает их после обновления.

Дизайн, структура страниц, логотип и программные функции меняются разработчиком.

## Совместная работа

Если другой редактор уже сохранил изменения, устаревшая вкладка получит сообщение о конфликте. Нажмите «Резервная копия»: сохранится ваша отклонённая публикация. Перезагрузите страницу и перенесите нужные правки в актуальную версию. Не импортируйте старую копию поверх чужих правок без сверки.

## Копии

«Резервная копия» скачивает JSON с карточками, категориями и текстами. «Загрузить резервную копию» заменяет данные сайта после подтверждения. Старые JSON с встроенными фото поддерживаются. Импорт и удаление публикуются сразу.

«Копия данных (.zip)» — технический снимок для разработчика, для публикации он больше не нужен. JSON и ZIP содержат ссылки на фотографии. Базу и файлы S3/Blob нужно резервировать отдельно.

Опубликованные данные доступны со всех компьютеров и не зависят от очистки браузера. Старый браузерный черновик автоматически не переносится: заранее экспортируйте его прежним редактором и импортируйте сюда.
